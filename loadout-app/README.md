# Loadout

Real fitness-tracking app: workouts, science-backed program library, leaderboard,
gym floor chat, and 100 achievements — backed by Supabase (auth + database).

## Setup

1. Run the SQL in `supabase-migration.sql` in your Supabase project's SQL Editor
   (in addition to the original schema from the launch guide).
2. `npm install`
3. `npm run dev` to run locally, or push to GitHub and deploy via Vercel.

Your Supabase URL and public key are already set in `src/supabaseClient.js`.
